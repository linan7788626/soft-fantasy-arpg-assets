# Godot 原生素材导入试验

本目录是一个独立 Godot 4.x 测试工程，读取基础套件的原图和同一份切帧/Pivot 清单，不改写 PNG。它用于验证引擎资源导入、四方向独立待机/行走/推箱状态、平滑推箱、压力板激活/复位与门状态，不代表完整游戏已经移植，也不代表 Unity 验收通过。

## 打开

在仓库根目录运行 `npm run build:godot`，然后用 Godot 打开本目录的 `project.godot`，运行主场景。方向键或 WASD 移动，E 推箱，1/2/3切换大厅、L形回廊和机关房。箱子推到压力板后开门，继续推离会复位。脚底与接触点来自清单；推箱先走到接触处，再同步发力，松手过渡回待机。箱子地面碰撞与高于地面的绘制轮廓分开。

`Art/` 是可重建的原图副本，不提交 Git；`.godot/` 是引擎缓存。构建会逐字节复制来源，不裁图、不去底、不缩放。`AtlasTexture.region`、`AnimatedSprite2D.offset` 和 scale 只在引擎渲染时应用，四方向分别使用独立原图，不以镜像代替。

## 验证

`npm run test:godot` 先构建副本，再调用真实 Godot Editor 无界面导入，随后运行引擎场景的验收流程。默认引擎路径 `/Applications/Godot.app/Contents/MacOS/Godot`，其他安装位置可用环境变量 `GODOT_BIN` 指定。

设置 `GODOT_RENDER=1` 再运行测试会打开真实渲染窗口并保存引擎截图。无界面报告只证明引擎导入与运行逻辑，不能代替画面检查。最新结果在 `Validation/report.json`；导入和运行日志在同目录。测试失败或缺少引擎时不得用旧报告宣称当前通过。

## 范围

- 每个方向六帧行走、四帧推箱及一个独立静止站姿。动作使用固定尺度；屈膝不重新缩放整帧。没有呼吸循环。
- 图集为试验级动作，装备一致性、动态轮廓和连续步态需人工视觉检查。
- 本工程演示三种布局，墙帽/墙面几何与网页共用一份清单；不复制网页的全部调试工具。
- 原有地板尚不是完整自动铺砖集；更复杂地牢、攻击/受击和其他机关留待本批验收后扩充。
