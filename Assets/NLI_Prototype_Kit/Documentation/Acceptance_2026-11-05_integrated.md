# 加高围墙与一体门洞 · 2026-11-05

## 交付

针对“墙和门太矮、独立门框拼接感强”的反馈，套件更新为 `0.5.0-integrated-room`。围墙总投影高度由88提高至168逻辑像素，墙面高度由48提高至128；占地厚40、内外角半径12保持不变。奶油色圆润石材以32px层高重复，避免纵向拉长石块，沿用此前认可的柔和蓝灰墙帽。

入口改为在连续墙面中直接扣除80×104的圆角门洞，上方墙帽不断开，周围石缝沿用同一世界坐标。独立石门框、门墩和顶盖不再绘制。新增 `Sprites/Door_Leaf_Embedded_v5.png`，仅含蓝色木门扇和金属装饰，嵌入76×100的区域；开门时隐藏门扇，门洞及其周围墙体不变。门口原独立门墩留下的碰撞格同时移除，北墙其余区域仍阻挡通行。

高墙会向屏幕上方投影，机关房原单行内部通道被遮挡。因此将内部开口扩至第3至5行，并将箱子、压力板移至第3行；实际地面与可行走路径均验证通过。大厅与L形回廊布局未改。

## 原生图像

本批只新增1张原生PNG，1156×1360、RGBA。使用内置image_gen，以此前门和小城堡为风格参考；交付文件逐字节复制生成输出。提示词、参考图、原始输出路径和SHA-256见 `round5-generation.json`。此前所有原图和224项基础素材保留，没有本地抠图、缩放、裁切或模糊处理。

套件累计保留25张原图；当前预览和引擎加载19张，清单包含10项模块和12项动作clip记录，共22条。旧版独立开/关门图留在素材目录归档，当前开门状态直接显示门洞，不再加载一张开门框图。角色仍为24帧行走、16帧推箱和4个独立待机姿态。

## 渲染

网页与Godot读取同一份 `walls` 几何、门洞轮廓和门扇位置。网页使用墙面裁切；Godot缓存多边形，通过空洞扣除保留室内地板与门洞，墙帽按世界坐标重复纹理。前景高墙和入口外侧的遮挡顺序同步处理。

旧版的墙帽连续性检查曾跳过独立门框覆盖区域，本批已将入口纳入采样。新增 `integrated-door.mjs` 在修改前因墙面高度48小于104而失败，修改后检查墙面高度、实际门洞透明度、入口上方墙帽连续性、原门墩碰撞和机关房可见通道。

## 查看与边界

直接打开 `Prototypes/DungeonWalk/index.html`，或使用本地预览服务。切换房间与门状态可检查衔接；Godot先运行 `npm run build:godot`，再打开独立工程并按1/2/3切换布局。

本批完成几何、渲染和交互验证，美术观感仍由用户确认。高墙会遮挡靠墙角色，尚未实现游戏中的遮挡淡化；门外仅有出口测试地砖，未接入关卡切换。完整自动铺砖、Unity Editor与完整PyQuest运行时集成尚未验收。
