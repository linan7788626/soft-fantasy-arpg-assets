# Provenance — v0.2

219 original entries were independently redrawn with built-in image_gen using the old Source_Crops as subject references and the approved portal/castles as style references. Every final generated PNG is copied byte-for-byte into Sprites and Source/Generated. No background removal, cropping or resizing was performed on generated outputs.

The four approved additions from v0.1.1 remain byte-identical. All old source crops and the original RGB atlas are retained; the prior sprites are archived under Source/Legacy_Sprites solely for comparison. Their old approximate alpha recovery is not used for the new images.

Generation_Records contains actual prompts, reference paths, dimensions, hashes, visual checks and any repair history for all 219 redraws. Absolute tool paths are historical provenance; use package-relative paths to locate delivered files.

No downloaded PixelFrog / Tiny Swords files are included. This is not an official extension or endorsement of another asset pack.
